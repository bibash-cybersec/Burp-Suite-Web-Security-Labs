A practical cybersecurity learning repository documenting my hands-on experience with **Burp Suite Community Edition** and web application security testing.

The purpose of this repository is to demonstrate my understanding of HTTP traffic, web application behaviour, Burp Suite workflows, and common web security vulnerabilities through authorized security labs.

---

## 🎯 Objectives

- Understand how Burp Suite works as an interception proxy
- Analyze HTTP requests and responses
- Intercept and modify web traffic
- Use Burp Repeater for manual request testing
- Understand Intruder and payload-based testing
- Analyze authentication and session behaviour
- Study common web application vulnerabilities
- Document findings using a professional security-testing methodology
- Build practical web security skills through PortSwigger Web Security Academy labs

Each completed lab contains selected screenshots demonstrating the practical work performed in Burp Suite.

## 🧠 Methodology

For each security lab, I document:

1. **Objective**
2. **Environment**
3. **Initial observation**
4. **Testing methodology**
5. **Burp Suite technique used**
6. **Request/response analysis**
7. **Result**
8. **Security impact**
9. **Remediation**
10. **Key learning**

This approach is intended to demonstrate not only tool usage, but also the reasoning behind the testing process.

---

## ⚖️ Responsible Security Testing

All practical testing documented in this repository is performed against:

- PortSwigger Web Security Academy labs
- Intentionally vulnerable applications
- My own laboratory environments
- Systems for which I have explicit authorization to test

No unauthorized systems are targeted.
